# 전국 어린이 보호구역 안전지도

PRD.md 기준으로 구현된 **바닐라 HTML/CSS/JavaScript** 웹 앱입니다.
번들러, 트랜스파일러, npm 패키지, node_modules를 전혀 사용하지 않았습니다.
지도(Leaflet)와 폰트만 CDN `<script>`/`<link>` 태그로 불러옵니다.

## 실행 방법

브라우저 보안 정책상 `fetch()`로 로컬 JSON 파일을 읽으려면 `file://`로 직접 열면 안 되고,
반드시 **로컬 웹 서버**를 통해 열어야 합니다. (Node.js 설치/의존성 불필요, 파이썬 내장 서버 사용)

```bash
cd project
python3 -m http.server 8000
```

이후 브라우저에서 `http://localhost:8000` 접속.

(파이썬이 없다면 VS Code의 "Live Server" 확장 등 아무 정적 파일 서버나 사용해도 됩니다.)

## 폴더 구조

```
project/
 ├─ index.html                 # 메인 페이지
 ├─ style.css                  # 전체 스타일
 ├─ js/
 │   ├─ popup.js                # 마커 팝업 HTML 생성
 │   ├─ map.js                  # Leaflet 지도/마커 클러스터/경로 렌더링
 │   ├─ filter.js                # 사이드바 필터(시설종류/CCTV)
 │   ├─ route.js                 # 출발지·도착지 지정, 최단/보호구역 경유 경로
 │   └─ app.js                   # 데이터 로드 및 초기화
 ├─ data/
 │   └─ child_safety_zones.json  # 원본 CSV(CP949) → UTF-8 JSON 변환본, 14,647건
 └─ PRD.md
```

## 구현된 기능

1. **마커 표시**: 위도/경도 기준 전국 14,647개 어린이보호구역을 지도에 표시 (성능을 위해 마커 클러스터링 적용)
2. **CCTV 색상 구분**: 설치(Y) = 파란색, 미설치(N) = 빨간색
3. **사이드바 필터**: 시설종류(11종 체크박스) + CCTV설치여부(전체/설치/미설치)
4. **마커 팝업**: 대상시설명 / 주소 / 보호구역도로폭 / 관할경찰서명 (+CCTV 뱃지)
5. **안전 경로 안내**:
   - 출발지·도착지를 지도 클릭 또는 주소 검색(Nominatim)으로 지정
   - OSRM 공개 라우팅 서버로 **도보(보행자) 기준** "최단 경로" 계산
   - 출발~도착 사이 어린이보호구역을 자동 선정해 경유지로 삼은 "보호구역 경유 경로" 계산 및 비교 표시

## 알아두면 좋은 점 (PRD 8장 열린 이슈에 대한 구현 결정)

- **라우팅/지오코딩**: 도보 경로는 무료 공개 OSRM 도보(foot) 라우팅 서버
  (`routing.openstreetmap.de/routed-foot`)를, 주소 검색은 Nominatim
  (`nominatim.openstreetmap.org`)을 사용합니다. 요청량이 많거나 상업적으로
  운영할 경우 자체 라우팅 서버로 교체가 필요합니다.
- **"경유" 판정 기준**: 출발-도착 직선 경로 기준 좌우 약 300m~2.5km(경로 길이에 비례) 폭
  안에 있는 보호구역 중 경로 진행 방향 순서로 최대 5곳을 선정해 실제 경유지로 강제 라우팅합니다.
- **대용량 데이터 로딩**: 최초 접속 시 전체 14,647건을 한 번에 불러오고,
  `Leaflet.markercluster`의 `chunkedLoading`으로 렌더링 버벅임을 줄였습니다.
  (뷰포트 기준 지연 로딩은 이번 버전 범위에 포함하지 않았습니다.)
